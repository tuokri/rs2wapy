The allow and deny patterns are the part of the URL in the webadmin after /ServerAdmin. For example, the pattern for this page is: /multiadmin, and the full URL is /ServerAdmin/multiadmin. The patterns may contain the wildcards * and **, the latter wildcard is greedy. The pattern /foo/*/bar would match /foo/quux/bar, but not /foo/bar. The pattern /xxx**y would match /xxx/something/yyy, the pattern /xxx*y would not.

Certain pages provide more granular permission control. For example the settings pages can filter on settings groups, or filter what game type or mutator can be edited.

To see what privilege URLs where checked for given pages you can enable the privilege log with the next button: . The privilege log can be shown by pressing the Π button in the lower left corner of the screen.
